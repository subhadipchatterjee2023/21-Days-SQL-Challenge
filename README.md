## 🚀 Overview  
Welcome to my **21 Days SQL Challenge** — a journey of learning, consistency, and growth in SQL!  
This challenge focuses on mastering real-world SQL problems one query at a time, covering everything from basics to analytical case studies.

I’m participating in this challenge with the **Indian Data Club**, supported by **DPDzero**, and inspired by **Codebasics**.

---

## 📘 What You’ll Find Here  
✅ Daily SQL challenges with problem statements and optimized solutions  
✅ Real-world examples of business scenarios  
✅ Learnings and takeaways from each challenge  
✅ Organized folders for easy navigation  

---

## 🧩 Folder Structure  
📂 **Data Files** — raw datasets used in the exercises  
📂 **Posters** — daily challenge posters and visuals  
📂 **SQL Query Files** — `.sql` scripts for each day  
📂 **SQL Query Images** — screenshots of query outputs

## 💡 Why I Started This Challenge  
- To build **daily consistency** in learning SQL 🧠  
- To strengthen **problem-solving skills** using real data  
- To showcase my **data journey publicly** 🚀  
- To connect with like-minded **data enthusiasts** 💬
